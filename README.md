# Azure_Speech_Studio-Language-Studio
Este repositório foi criado como parte de um laboratório prático com o objetivo de aprofundar o uso das ferramentas Azure Speech Studio e Language Studio, focando na análise de fala e linguagem natural com soluções baseadas em Inteligência Artificial


O principal objetivo deste laboratório é:

Explorar as capacidades das ferramentas Azure Cognitive Services para voz e linguagem natural.
Desenvolver habilidades práticas na criação de modelos de transcrição, compreensão de linguagem e análise de sentimentos.
Documentar todo o processo por meio de anotações, exemplos e reflexões para uso futuro.

Etapas Realizadas
1. Speech Studio
Criada transcrição de áudios com diferentes sotaques
Gerado texto a partir de fala com vocabulário personalizado
Treinado modelo de voz com dados específicos
Testado recurso de leitura natural com vozes neurais

2. Language Studio
Criada análise de sentimentos para blocos de texto
Identificadas entidades como nomes, locais e datas
Utilizado classificador de intenções com exemplo de chatbot
Exportação de modelos para integração com aplicações externas

Insights e Aprendizados
A personalização de voz permite adaptar soluções a contextos específicos, como setores de atendimento.
O modelo de sentimentos pode ser incorporado em sistemas de SAC e análise de feedbacks de clientes.
A criação de intents e entidades facilita o desenvolvimento de chatbots inteligentes.
As ferramentas possuem interfaces amigáveis e permitem testes diretos antes da publicação.
